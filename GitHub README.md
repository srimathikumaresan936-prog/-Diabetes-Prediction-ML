# Diabetes Prediction Using Machine Learning

## 📌 Project Overview

This project is a **machine-learning classification project** that predicts the diabetes status of an input based on health-related features.

The project compares two machine-learning algorithms:

- Logistic Regression
- Random Forest Classifier

After comparing their performance, **Random Forest** was selected for the final prediction system.

> **Note:** This project is created for educational purposes. The model's output is a machine-learning classification result and should not be considered a medical diagnosis.

---

## 🎯 Objective

The main objective of this project is to:

- Load and understand a diabetes dataset
- Handle missing values
- Convert categorical data into numerical form
- Split the dataset into training and testing data
- Train classification models
- Compare model performance
- Build a user-input prediction system

---

## 📊 Dataset

The dataset contains **120 records and 14 original features/columns**.

### Features

- Age
- Gender
- BMI
- Waist Circumference
- Blood Pressure
- Fasting Glucose
- HbA1c
- Insulin
- Physical Activity
- Family History
- Smoking
- Diet
- Pregnancies
- Diabetes Status

### Target

The target variable is:

- `Normal` → 0
- `Prediabetes` → 1
- `Diabetes` → 2

---

## 🧹 Data Preprocessing

The following preprocessing steps were performed:

1. Loaded the dataset using Pandas.
2. Checked the dataset structure and data types.
3. Identified missing values.
4. Filled missing numerical values using the **median**.
5. Filled the missing Diet value using the **mode**.
6. Converted categorical features into numerical values using **One-Hot Encoding**.
7. Converted the target classes into numerical values.
8. Split the dataset into training and testing sets using an 80:20 ratio.

---

## 🤖 Machine Learning Models

### 1. Logistic Regression

Logistic Regression was trained as the first classification model.

**Test Accuracy: 58.33%**

### 2. Random Forest

Random Forest was trained as the second classification model.

**Test Accuracy: 70.83%**

Since Random Forest achieved better test accuracy on this dataset, it was selected as the final model.

---

## 📈 Model Performance

| Model | Test Accuracy |
|---|---:|
| Logistic Regression | 58.33% |
| Random Forest | **70.83%** |

Random Forest performed better than Logistic Regression on the test set.
